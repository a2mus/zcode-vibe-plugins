- (constraint) Brownfield: architecture ratified from existing v0.2.0 codebase, AGENTS.md, PRD (FR-1..FR-28, RULE-1..RULE-6), DESIGN.md, EXPERIENCE.md
- (decision) AD-1 Strict 4-Layer Separation: Core Engine (debrief-engine.mjs) / MCP Transport (mcp-server.mjs) / Hook Runner (hook-runner.mjs) / Panel UI (panel.html). Each layer has exclusive runtime concerns. Prevents: cross-layer coupling, stdout corruption, testability loss.
- (decision) AD-2 Unidirectional Dependency: Panel->MCP->Engine, Hook->Engine. Engine never imports MCP or Hook; MCP never imports Hook; Panel communicates only via postMessage JSON-RPC. Prevents: circular dependencies, unit-testing Engine requiring MCP stdio setup.
- (decision) AD-3 Stdout Isolation (RULE-4): stdout in mcp-server.mjs reserved for JSON-RPC 2.0 frames; stdout in hook-runner.mjs reserved for single-line hook JSON; debrief-engine.mjs never reads stdin or writes stdout. Prevents: MCP frame corruption from debug logs.
- (decision) AD-4 Zero External Dependencies (RULE-2): All .mjs files use only node: built-in imports; panel.html uses zero external scripts/styles/fonts. No package.json. Prevents: supply-chain risk, install friction, bundler requirement.
- (decision) AD-5 State Ownership: Engine owns all file I/O (loadPersistedState, savePersistedState, confirmAndSaveLessonToZCodeMemory, saveStandaloneHtmlArtifact). MCP and Hook call Engine functions; Panel has no direct disk access. Prevents: concurrent state corruption, split persistence logic.
- (decision) AD-6 CSP & XSS Safety (RULE-3): panel.html enforces unsafeEval:false; no eval/new Function/inline onclick; all dynamic strings use escapeHtml(); embedded JSON escapes < as \u003c. Prevents: XSS in MCP App iframe, CSP violations.
- (decision) AD-7 Reading-Boundary Principle (RULE-1): STE-80 clarity applies only at publish/debrief time (vibe_debrief_publish, Stop hook). Never constrains agent mid-task reasoning. Prevents: agents dumbing down code or reasoning to meet readability rules.
- (decision) AD-8 4-File Version Sync (RULE-5): Version bumps must update plugin.json + mcp-server.mjs (serverInfo.version) + panel.html (appInfo.version) + hook-runner.mjs (additionalContext banner) together. Prevents: version drift across surfaces.
- (decision) AD-9 Panel-Host Communication: Panel communicates exclusively via postMessage JSON-RPC 2.0 (PROTOCOL_VERSION 2026-01-26). Outbound: ui/initialize, ui/notifications/initialized, tools/call, ui/message. Inbound: ping, ui/notifications/host-context-changed, ui/notifications/tool-result. Prevents: direct DOM access to host, network requests from panel, breaking MCP App sandbox.
- (decision) AD-10 Single-State-Render Architecture: Panel has one renderPanelState(state) entry point. All tool results and host notifications converge through it. Prevents: partial UI updates, stale card/tab state, render path fragmentation.
- (decision) AD-11 Never-Crash Hook Pattern: hook-runner.mjs wraps every I/O path in try/catch returning {} or null. readStdinJson returns {} on parse failure. tryOptionalAiDebriefSynthesis returns null on any error. Heuristic debrief always runs before AI attempt. Prevents: hook failure crashing ZCode session lifecycle.
- (decision) AD-12 Complexity Gate for Explainer Scenes: explainerScenes only populated when assessWorkflowComplexity scores >= 4 (complex), or explicitly overridden via complexityOverride or vibe_debrief_generate_explainer. Prevents: visual clutter on simple 1-2 file turns.
- (question) OQ-2 Resolution: Zero-dependency testability. Node 26+ ships node:test built-in. Engine's pure-function design (no stdin/stdout, all state via params+returns) makes it directly testable via tests/*.test.mjs with zero npm deps. Recommendation: ADOPT node --test suite for debrief-engine.mjs covering STE-80 metrics, complexity gate thresholds, escapeHtml, buildDefaultDiagram, and memory write paths.
- (question) OQ-3 Resolution: Hook AI synthesis (VIBE_DEBRIEF_OPENAI_KEY in Stop hook) coexists with CreateSession delegation (UserPromptSubmit Deep Refresh). They serve different triggers: Stop hook fires automatically at turn end (ambient enhancement); CreateSession fires on explicit user action (AI Explain button). Recommendation: KEEP both paths—deprecation would remove ambient fallback when agents skip vibe_debrief_publish. Mark Stop AI synthesis as 'optional ambient enhancement' and CreateSession as 'primary explicit refresh'.
