## Intent

**Problem:** Stories 8.1–8.5 built the Palette C warm-charcoal tokens, closed larger type ramp, 3-tab `work`/`queue`/`project` shell, unified in-iframe overlay controller (`AD-17`), Work hero/Action Window/RD-8 disclosures, and Focus View across Work, Queue, and Project, landing 85 passing tests across `tests/panel-guards.test.mjs` (42) and `tests/panel-a11y.test.mjs` (43). ## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| Overlay close triggers & `aria-hidden` | Open overlay with stashed `pendingWorkspaceState`; click `#overlayCard`, then click `#overlayCloseBtn` or `#overlayLayer` backdrop; also call `closeOverlay()` while closed | `#overlayLayer` toggles `aria-hidden` `"true" → "false" → "true"`, `.visible`, `style.display` `"flex" → "none"`, empties `#overlayBody`; clicking `#overlayCard` keeps overlay open; clicking `#overlayCloseBtn` or `#overlayLayer` closes overlay, restores focus, and flushes stashed state | Calling `closeOverlay()` when closed is a safe no-op without throwing |
| Non-stacking overlay replacement | Open `insights` overlay, then call `openOverlay` for `queue-item` without closing first | Single `#overlayLayer` replaces `activeOverlay` in place (`isOverlayOpen() === true`, `targetType === "queue-item"`, `#overlayTitle` updated), never stacks a second dialog | N/A |
| Mid-flight `refreshState` during overlay open | Start `refreshState({ isBackground: true })` while idle (`autoRespondGetState: false`), call `openOverlay()` before RPC resolves, then resolve RPC | Response stashes into `pendingWorkspaceState` without updating background DOM while overlay is open; `closeOverlay()` flushes stashed state immediately (`0ms`) | Lock `isRefreshing` always resets to `false` |
| Escape & Tab edge cases in overlay | (a) Focus `INPUT` inside overlay + `Escape`; (b) focus `#overlayCloseBtn` + `Escape`; (c) set `selectOpenUntil > Date.now()` inside overlay + `Tab` | (a) Blurs input, closes overlay, flushes stash, restores focus; (b) closes overlay, flushes stash; (c) clears `selectOpenUntil = 0` AND traps `Tab` inside overlay focusables | Capture-phase listener prevents background leakage |
| `reconcileActiveOverlay` edge cases | (a) Call while no overlay open; (b) focus `#overlay-q-done`, reconcile to `status: "done"` (disables `#overlay-q-done`); (c) explicit `refreshState({ isBackground: false })` while overlay open (item updated vs removed) | (a) Returns `false` no-op; (b) moves focus to an enabled focusable inside `#overlayLayer`; (c) clears stale `pendingWorkspaceState`, updates overlay in place or closes with `"That item is no longer available"` + active tab heading focus | Disabled/detached focus targets always fall back to visible overlay controls or tab heading |
| `selectedRecKeys` lifecycle | Check 2 recs; next poll drops 1 rec; batch enqueue remaining rec; click batch enqueue with 0 checked; toggle Select All / Deselect All | Dropped rec key is pruned from `selectedRecKeys` and count updates; successful `btnQueueSelectedRecs` clears `selectedRecKeys` (`size === 0`) and switches to `queue`; empty click shows warning toast and skips RPC | Stale keys never trigger orphan queue additions |
| `getRecommendationBaseModelId` 5-tier consistency | Test object `recommendedModel`, string `recommendedModel`, omitted with `current: true` model, omitted with non-current models, omitted with `[]` / `null` rec; edit model in Action Window on omitted-`recommendedModel` rec and run card action + batch queue | Resolves `explicit` / `string` / `current` / `first` / `""` consistently; card render, Action Window, card action handler, and batch enqueue all compute the same base model ID so `resolveUserModel` preserves the user choice | Empty `availableModels` safely returns `""` without throwing |
| `AD-17` §3 interactive-descendant guard | Direct click targets (`BUTTON`, `A`, `INPUT`, `SELECT`, `TEXTAREA`, `LABEL`, `[role="tab"]`, `.status-pill`, `.pill`), nested `<span>` inside interactive parent via `closest()`, non-interactive `<div>`/`<span>`, and container self-click | Returns `true` for all direct and nested interactive descendants; returns `false` for non-interactive children and container self-click | Missing `target` or missing `closest` safely returns `false` |
| 3-tab ARIA + dialog + disclosure static & rendered checks | Parse `PANEL_HTML` and run `createStubbedA11yEnvironment` | Exactly 3 `role="tab"` and 3 `role="tabpanel"` with matched `aria-controls`/`aria-labelledby`/`aria-describedby`; `switchTab` & `handleTabKeydown` move focus and ARIA state across all 3 tabs; `#overlayLayer` exposes valid dialog ARIA + overlay `<label for>` + `⤢` `aria-label`s; all 3 RD-8 disclosures toggle `false → true → false` with live counts, matched `aria-controls`, and constant default `.btn` weight | Invalid/legacy tab IDs normalize to `work` |
| Complete Palette C dark/light WCAG contrast | Extract all `:root` and `body.theme-light` tokens from `PANEL_HTML`, compute `contrastRatio` & `compositeColor` | Every Palette C token matches `DESIGN.md`; all essential text pairs (`text-primary`, `text-secondary`, `text-muted` on `bg-primary`/`bg-secondary`/`bg-tertiary`; 5 semantic hues on `bg-primary`/`bg-secondary` and on `*-soft` over both surfaces; `--on-primary` on all 4 gradient stops; `.diff-add`/`.diff-del` 16% mixes) reach `>= 4.5:1`; focus indicators (`--accent`, `--purple` across all 3 surfaces) reach `>= 3.0:1`; decorative `--border` stays `< 3.0:1` with distinct surface tones | Any Palette C token regression fails deterministically with exact pair names and measured ratio |
